## 结论
1. 本文成功率 100.0%，为全部方法中最高（其余 86–99%）。
2. 本文最坏腕部力 38.09 N 满足 ≤40 N 判据；B1 亦达标（32.28 N）但成功率仅 88%。
3. C0 / B2 / B4 最坏力均超线（54.15 / 56.26 / 67.94 N）。
4. 两个消融（A2 去阶段1、A3 去力约束）均使最坏力由达标退化为超线（47.03 / 48.49 N）。
5. 典型工况（中位 13–16 N、P90 27–30 N）各方法接近，差异集中在最坏工况/尾部。
