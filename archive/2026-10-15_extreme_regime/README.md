# 2026-10-15 极限工况（64 组边界组合）评估 + 第三章图表更新

## 极限工况的定义与执行方式
- 64 组 = 8 个姿态组合 × 8 个位置组合
  - 位置：x ∈ {−12, 0} cm、y ∈ {−12, +12} cm、z ∈ {0, −12} cm
  - 姿态：roll/pitch/yaw 各 ∈ {−3°, +3°}
- 执行：一次评估、**64 个环境**，环境 i ↔ 第 i 个工况，每个工况跑一遍（450 步）
- 实现：`env.task.extreme_sweep=True`（reset 时按环境索引取固定边界偏移，覆盖随机化）
- 评价：seed 1234、只评估 last 检查点、腕部 6 维指标
- **口径提醒**：每工况仅 1 次回合，故单工况成败带随机性，应看整体通过率与最坏力

## 结论
1. 极限工况下本文成功率 95.3%，断层领先（C0 34.4%、B1/B2 46.9%、B4 70.3%），说明基线在初始偏差取边界值时大面积失败，本文抗退化能力最强。
2. 极限工况下所有方法最坏腕部力均超过 40 N（本文 60.87 N，A3 最高 77.21 N），说明 40 N 判据适用于规范工况（本文 38.09 N 达标），极限工况用作压力测试与相对比较。
3. A3（去除接触段连续力约束）在极限工况下最坏力 77.21 N 为全部实验最高，验证分段力上限对最坏接触力的压制作用。
4. B1/B2 极限最坏力较低（36.07 / 33.66 N）但成功率仅 46.9%，低受力是任务未完成的结果，评价必须与成功率联合解读。
